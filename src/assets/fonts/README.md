# Self-hosted font fallbacks

These files replace third-party render-blocking font stylesheets while the
licensed CREOVA display faces are not yet available as webfont files.

- General Sans: sourced from Fontshare under the ITF Free Font License.
- Instrument Serif: sourced from Google Fonts under the SIL Open Font License.

Source pages:

- https://www.fontshare.com/fonts/general-sans
- https://fonts.google.com/specimen/Instrument+Serif
