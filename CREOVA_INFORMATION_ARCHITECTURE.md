# CREOVA Information Architecture

## Primary public navigation

1. Work
2. Services
3. Resources
4. Community
5. Our Brands
6. About
7. Start a project

This order is retained because it moves from proof to offer, usefulness, relationship, broader ecosystem, identity, and conversion.

## Route inventory

| Group | Routes |
| --- | --- |
| Core | `/`, `/work`, `/services`, `/community`, `/resources`, `/ventures`, `/about`, `/start-a-project` |
| Proof | `/work/:published-case-study`, external Pixieset galleries |
| Editorial | `/journal`, `/journal/:post` |
| Local discovery | Data-driven service-area routes |
| Trust/legal | `/terms-of-service`, `/privacy-policy` |
| Localized | Equivalent routes under `/fr` |
| Legacy | Redirects from contact, pricing, shop, events, booking, rental, checkout, and related old paths |
| Restricted | Admin submissions, analytics, refunds, galleries, hub, and database routes |

## Page jobs

| Page | Primary job | Primary action |
| --- | --- | --- |
| Home | Establish value and credibility | Start a project |
| Work | Prove capability with public evidence | Open a case study/gallery |
| Services | Help a buyer select the right engagement | Start a project |
| Community | Clarify collaboration, partner, and funder routes | Choose a relationship |
| Resources | Give useful planning tools and learning | Open/download a resource |
| Ventures | Explain adjacent brands and their stage | Visit only when ready |
| About | Establish founder, values, and cultural approach | Discuss a project |
| Contact | Qualify and submit an inquiry | Submit or email |

## Content rules

- One page, one primary job.
- One primary CTA label per intent; avoid synonyms that imply different flows.
- Work claims link to public proof where possible.
- “In development” ventures remain visually distinct from available offers.
- French routes must preserve equivalent information and interaction, not merely approximate tone.
