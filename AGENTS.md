# Repository Engineering & AI Agent Contract (`AGENTS.md`)

## 1. Decision Hierarchy
1. Verified repository code, lockfiles (`package-lock.json`, `workers/api/package-lock.json`), and passing tests
2. Accepted ADRs in `docs/adr/` (e.g., `docs/adr/0001-cloudflare-worker-d1-edge-api-and-prerendered-spa.md`)
3. Repository-specific constraints in `.ai/project.yaml`, `CLAUDE.md`, and this file
4. Shared Engineering Governance Standard (`v1.0`)

## 2. Hard Invariants for All Agents (Antigravity, Devin, Claude, Codex, GStack)
- **Epistemic Honesty:** Never claim a feature, model, compliance standard, or cloud integration is implemented if backed by mocks, timers, or stubs. Label conceptual/thesis work explicitly (`docs/archive/EAST-AFRICA-FINTECH-THESIS.md`).
- **No Unapproved Dependencies:** Do not add runtime packages to `package.json` or `workers/api/package.json` without explicit task approval and lockfile updates.
- **No Harness or Asset Pollution:** Never commit vendored skill packs (`gstack/`, `.cursor/`), `attached_assets/`, `build/`, `dist/`, `.env`, `.dev.vars`, `.secrets.json`, or autogenerated `utils/supabase/info.tsx` files.
- **Security Fail-Closed:**
  - Never introduce fallback secrets, unverified token decoding, or wildcard (`*`) CORS origins.
  - Keep all email-triggering `/submit-*` public mutation endpoints behind `turnstileGate` (rejecting Cloudflare's dummy test keys and failing closed with `503` when `TURNSTILE_SECRET_KEY` is unconfigured, except on loopback requests when `CREOVA_ENV` matches exact local values `development`, `dev`, `local`, or `test`). Note: `/subscribe-event-interest` intentionally omits Turnstile and instead enforces its strict per-IP daily write cap (`SIGNUP_WRITES_PER_IP_PER_DAY`) without sending outbound email.
  - Never place secret keys in client-side `VITE_*` variables.
  - Keep all Cloudflare D1 SQL queries strictly parameterized (`db.prepare(...).bind(...)`).
- **PR & Verification Discipline:** Place imports at module top. Every change must pass all verification gates in `.ai/project.yaml` locally (`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`) and land via an atomic Conventional Commit pull request. If any gate cannot run, report `NOT VERIFIED` with the reason. Never force-push or modify remotes without explicit approval.
