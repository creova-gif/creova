# CREOVA community resource documents

These bilingual PDFs extend the existing CREOVA resource library with practical planning aids for cultural and community work. They are public educational resources, not contracts or legal advice.

## Design system

- Letter format, one English page and one French page.
- Burgundy, warm cream, and gold follow the current CREOVA website palette.
- The CREOVA wordmark is used as a quiet publisher mark, with an abstract background motif that does not compete with each document's purpose.
- Every page includes a document identifier, revision date, language marker, and page number.

## Build

Run `npm run build:resources`. The script requires Google Chrome on macOS and writes the final PDFs to `public/resources/`.

Source content and print styles live in `scripts/build-resource-pdfs.mjs`. Generated HTML is temporary and remains under `.context/resource-pdf-build/`.

## Published files

- `creova-event-story-run-of-show.pdf`
- `creova-consent-content-rights-planner.pdf`
- `creova-community-story-interview-guide.pdf`

The original Project Story Brief and Equipment & Media Checklist remain unchanged and are not regenerated by this script.
